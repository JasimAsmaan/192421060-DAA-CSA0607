## Project Description

This project focuses on debugging and optimising the SentinelOps Security Operations Centre (SOC) Alert-Triage Module.

The original Python program contains nine logical defects in four major operations:

1. Alert sorting using Insertion Sort.
2. IP blocklist checking using Sequential Search.
3. Attack signature searching using Brute-Force String Matching.
4. Closest login location calculation using Brute-Force Closest Pair.

## Objectives

- Identify all nine defects in the original program.
- Explain the root cause of each defect.
- Correct the program systematically.
- Optimise the corrected algorithms.
- Analyse time and space complexity.
- Compare original and optimised performance.
- Test normal and boundary cases.

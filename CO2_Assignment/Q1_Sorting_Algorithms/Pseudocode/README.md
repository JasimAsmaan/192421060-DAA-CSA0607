
# Q1 – Sorting Algorithms

## Problem Context
E-Commerce Order Processing

## Objective
To investigate and compare Selection Sort, Bubble Sort, and Insertion Sort under different input arrangements.

## Algorithms
1. Selection Sort
2. Bubble Sort
3. Insertion Sort

## Pseudocode
Pseudocode for all three algorithms will be documented here.

## Test Conditions
1. Randomly ordered dataset
2. Nearly sorted dataset
3. Already sorted dataset
4. Additional edge-case dataset

## Analysis
The algorithms will be compared using:
- Number of comparisons
- Number of swaps or movements
- Execution time, where useful

## Design Decision
Recommend an appropriate sorting algorithm for an e-commerce fulfilment centre where approximately 95% of existing orders are already correctly ordered.
